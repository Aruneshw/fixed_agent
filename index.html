Getting Started

Deploy in Seconds

Choose your preferred deployment method

Docker Compose

Recommended

Single command deployment for local development or production use.

terminal 
docker-compose up --build -d
Dashboard http://localhost
API http://localhost:8000

Kubernetes

Scalable

Deploy to any K8s cluster with persistent volumes and service discovery.

terminal 
kubectl apply -f k8s/pvc.yaml
kubectl apply -f k8s/backend-deployment.yaml
kubectl apply -f k8s/frontend-deployment.yaml
Manifests k8s/

CI/CD Pipeline

Automated

Push to main and GitHub Actions handles the rest — builds, tests, and deploys automatically.

.github/workflows/main.yml 
on:
  push:
    branches: [ main ]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker-compose build
